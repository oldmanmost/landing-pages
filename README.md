# 🌐 Landing Pages & Integration

Коллекция готовых HTML-шаблонов лендингов, квизов и примеров их бесшовной интеграции с Telegram-ботами для максимальной конверсии.

## 📂 Проекты в этом репозитории

### 1. [Tilda-like Templates](./tilda-templates)
Адаптивные одностраничные сайты с продающей структурой: оффер → боли → решение → кейсы → форма заявки.
- **Технологии:** HTML5, CSS3, Vanilla JS.
- **Время внедрения:** ~1 день.

### 2. [Quiz Landing](./quiz-landing)
Сайт-опросник с высокой конверсией (до 30%). Клиент отвечает на вопросы и оставляет контакт для получения результата.

### 3. [Landing + Bot Integration](./landing-bot-integration)
Готовые примеры связки: форма на сайте → отправка данных через Webhook → Telegram-бот начинает прогрев клиента.
