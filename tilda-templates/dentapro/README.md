# 💎 Шаблон лендинга "DentaPro"

Адаптивный, современный одностраничный сайт с продающей структурой. Идеально подходит для медицинских клиник, салонов красоты или любых услуг, где важна доверительная подача.

## 🎯 Особенности
- **Полная адаптивность:** Идеально смотрится на мобильных устройствах (60%+ трафика).
- **Продающая структура:** Hero-блок с оффером → Услуги с ценами → Форма захвата.
- **Лёгкость:** Чистый HTML/CSS без тяжёлых библиотек, загружается мгновенно.
- **Готовность к интеграции:** Форму легко подключить к Telegram-боту или Google Таблицам через JavaScript Fetch API.

## 🚀 Как использовать
1. Скачайте или откройте `index.html` в любом браузере.
2. Отредактируйте тексты, цены и контакты под вашу нишу.
3. Замените обработчик формы (`onsubmit`) на отправку данных в ваш Telegram-бот или CRM (примеры есть в репозитории `landing-bot-integration`).
