# 🔗 Связка Лендинг + Telegram-бот (SkillUp)

Демонстрация полноценной воронки продаж: пользователь оставляет заявку на сайте → данные улетают на сервер → пользователь перенаправляется в Telegram-бота → бот выдает лид-магнит и начинает прогрев.

## 🎯 Как это работает
1. Клиент заполняет форму на `index.html`.
2. JavaScript отправляет `POST`-запрос с данными (имя, телефон) на ваш сервер (`/webhook/skillup`).
3. Python-скрипт (`bot.py`) мгновенно пересылает эти данные администратору в Telegram.
4. Клиента автоматически перенаправляет в Telegram-бота по ссылке `t.me/bot?start=free_lesson`.
5. Бот выдаёт бесплатный урок и предлагает записаться на полный курс.

## 🚀 Преимущества такой связки
- **Нулевая потеря лидов:** Данные дублируются и в CRM/админу, и в чат с клиентом.
- **Высокая доставляемость:** Сообщения в Telegram читают в 5 раз чаще, чем email-рассылки.
- **Автоматический прогрев:** Бот продолжает работать с клиентом 24/7 без участия менеджера.
